# 💼 Salary Comparison

## 📖 Overview
Welcome to the Salary Comparison project! This repository is part of an initiative to explore tech industry salaries and uncover insights into trends, roles, and regional differences. 📊

## 🏆 DataCamp Competition
Created for the [DataCamp Demystifying Data Salaries Level 1 Competition](https://app.datacamp.com/learn/competitions/demystifying-data-salaries-level-1). The goal is to analyze salary data and derive meaningful insights. 🚀

## 📂 Repository Structure
- `notebook.ipynb`: Main analysis and visualizations.
- `salaries.csv`: Salary dataset.
- `salary_comparison.png`: Charts and visualizations.
- `README.md`: You're reading it! 😊

## 📊 Data Analysis
Our analysis covers:
- 🌍 **Geographical Salary Distribution**
- 💼 **Role-wise Salary Comparison**
- 📈 **Trends Over Time**
- 🏅 **Impact of Experience & Skills**

Tools used: **Pandas**, **NumPy**, **Matplotlib**, **Seaborn**.

## 📈 How to Use
Check out `notebook.ipynb` for the full analysis. Feel free to tweak the code and explore the data your way! 🔍

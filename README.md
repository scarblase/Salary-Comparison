# 💼 Salary Comparison

## 📖 Overview
Welcome to the **Salary Comparison** project! This repository is part of an international HR consultancy initiative aimed at helping companies attract and retain top talent in the competitive tech industry. Through this project, we provide valuable insights into salary trends and comparisons within the tech industry.

## 🏆 DataCamp Competition
This repository was created for the [**DataCamp Demystifying Data Salaries Level 1 Competition**](https://app.datacamp.com/learn/competitions/demystifying-data-salaries-level-1).  
The goal of this competition is to analyze salary data and derive meaningful insights to better understand salary dynamics across different roles, regions, and timeframes.  

---

## 📂 Repository Structure
- `notebook.ipynb`: The main Jupyter Notebook containing the complete analysis and visualizations.  
- `data/`: Folder containing the salary dataset (if applicable).  
- `images/`: Contains visualizations and charts generated during analysis.  
- `LICENSE`: Contains licensing information.  
- `README.md`: Project documentation (this file).  

---

## 📊 Data Analysis
The analysis includes:  
- **Geographical Salary Distribution:** Comparing salaries across regions.  
- **Role-wise Salary Comparison:** Understanding how job titles impact earnings.  
- **Trends Over Time:** Examining salary growth and fluctuations.  
- **Impact of Experience & Skills:** Analyzing how experience level and skill sets affect salaries.  

We leverage Python libraries such as **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn** for data manipulation and visualization.

## 🚀 Getting Started
To explore or reproduce this analysis, follow these instructions:

### ✅ Prerequisites
Ensure you have **Python 3.8 or higher** installed. You can set up your environment using **Anaconda** or **pip**.  

---

### 🔧 Installation

#### Using Anaconda
1. **Download and install Anaconda**: [Get Anaconda](https://www.anaconda.com/products/individual)  
2. **Create a virtual environment (optional):**  
   ```sh
   conda create -n salary-comparison python=3.8
   conda activate salary-comparison
   ```
3. **Install Jupyter Notebook:**  
   ```sh
   conda install jupyter
   ```
4. **Clone the repository and navigate to the project directory:**  
   ```sh
   git clone https://github.com/scarblase/Salary-Comparison.git
   cd Salary-Comparison
   ```
5. **Launch Jupyter Notebook:**  
   ```sh
   jupyter notebook
   ```

---

#### Using pip
1. **Install Jupyter Notebook using pip:**  
   ```sh
   pip install jupyter
   ```
2. **Clone the repository and navigate to the project directory:**  
   ```sh
   git clone https://github.com/scarblase/Salary-Comparison.git
   cd Salary-Comparison
   ```
3. **Launch Jupyter Notebook:**  
   ```sh
   jupyter notebook
   ```
